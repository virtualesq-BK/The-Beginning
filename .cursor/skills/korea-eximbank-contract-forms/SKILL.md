# Korea Eximbank 영문국제계약양식

## When to use
- 해외 대출·PF·수출·건설·보증/L/C 계약 1차 검토

## Quick facts
- 총 **77건** DOC, 페이지네이션 **1/8**, 번호 내림차순 77→1
- 대분류 10개: 국제금융계약, 합작투자, 수출, 건설공사, 프랜차이즈·라이센스, 판매권수여·대리상, 약속어음, 보증서·신용장·보장장 등, 기타, 계약관련 서류
- 확인된 1페이지(No.77–68): Direct Loan, Overseas Project Loan (Revolving), Interbank Export Loan, Comprehensive Interbank Export Credit, Common Agreement, Direct Agreement, Individual Facility, Intercreditor, Agency, Shareholder's Agreement
- 서식은 **참고·편집용**; 법적 효력·최종 검토는 전문가 영역. DOC 원문은 은행 사이트에서만 다운로드 (저장소에 복제하지 않음)

## Workflow for The Beginning
1. 업로드 계약의 거래 유형을 Eximbank 대분류에 매핑
2. PF/대출이면 [pf-loan-notes.md](pf-loan-notes.md) 점검 항목으로 리스크·협상 포인트 보강
3. 조항 유형 연결: 지급조건·해지·준거법 → Loan 계열; 이행보증·분쟁해결 → Guarantee/L/C/Agency; Change Order·지체상금 → 건설공사
4. 고위험(준거법 일방 유리, Direct Agreement/Intercreditor 부재, 상환주체 불명 등)이면 전문가 연결 안내
5. 상세 목록·UI는 [download-catalog.md](download-catalog.md), 종합 노트는 [overview.md](overview.md)
