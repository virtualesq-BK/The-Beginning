# Standard Contract Forms (VC / SAFE / PIPE)

## When to use
- VC 라운드 / SAFE / PIPE / NVCA 패키지 검토
- UNDP 개인계약자(IC) 용역계약
- 한국 벤처투자 표준계약서 비교

## Related skills
- 해외 EPC·공급·구매·건설·NDA → `overseas-epc-supply-contracts`
- 수출입은행 영문국제계약양식 → `korea-eximbank-contract-forms`

## Quick map
| Family | Key docs |
|--------|----------|
| SAFE | Postmoney SAFE Valuation Cap Only |
| PIPE | SPA, RRA, Ordinary/Pre-Funded Warrant (FPI) |
| NVCA | COI, SPA, IRA, Voting, ROFR/Co-Sale, Indemnification, Management Rights |
| UNDP | Individual Contractor Contract |
| KR-VC | 벤처투자 표준계약서 양식 ZIP + 해설서 PDF |

## Workflow
1. 문서 패밀리 식별 (SAFE/PIPE/NVCA/UNDP/KR-VC)
2. 해당 참고 파일의 점검 힌트로 리스크·협상 포인트 보강
3. 고위험(청산우선권, anti-dilution, drag-along, 등록권 지연, IP 귀속 불명 등) 시 전문가 연결
