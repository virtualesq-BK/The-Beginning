# Overseas EPC / Supply / Project Contracts

## When to use
- EPC·턴키·해외 건설·가스필드 용역/구매
- 공급계약·Purchase Order·소프트웨어 라이선스
- NDA / CDA / 기밀유지
- KOGAS, Akkas, Iraq upstream, Oman 표준건설문서 언급 시

## Do not use for
- VC / SAFE / PIPE / NVCA 우선주 패키지 → `standard-contract-forms` 스킬
- 수출입은행 영문국제계약양식 → `korea-eximbank-contract-forms` 스킬

## Workflow for The Beginning
1. 업로드 문서 유형을 위 Family에 매핑
2. 해당 노트의 **점검 힌트**로 리스크·협상 체크리스트 보강
3. EPC/건설이면 특히 확인:
   - time for completion / **liquidated damages**
   - performance·reliability guarantees
   - contractor total maximum liability
   - variations / change orders
   - tests / takeover / defects liability
   - force majeure / suspension / termination
   - arbitration / governing law
4. Purchase/Supply면: delivery·title/risk·Incoterms, acceptance, warranty, payment
5. SVC면: scope/SOW, remuneration, HSE, indemnity, insurance, IP/documents ownership
6. NDA/CDA면: definition/exclusions, term/survival, residuals, purpose limitation
7. 고위험(일방적 준거법·과도한 LD·보증 공백·책임한도 불명·IP 귀속 불명)이면 전문가 연결 안내
8. 서식은 **참고용**; 법적 효력·최종 검토는 전문가 영역
